# 学部卒業論文「ゲーミフィケーションを適用した英語発音学習支援システム」にて開発したアプリケーション
<img width="355" height="458" alt="スクリーンショット 2025-10-10 19 08 48" src="https://github.com/user-attachments/assets/a7366453-5b80-45e0-8bdd-5c71221b99c0" />

学部卒業論文[「ゲーミフィケーションを適用した英語発音学習支援システム」](https://github.com/Somahc/thesis-bachelor/blob/main/main.pdf)にて開発し、実験で利用したアプリケーションです。

※現在は実験が終了したため、アプリケーションは使用できない状態です。

## 特徴
### 株式会社コト様より提供いただいた発音評定AIであるSeePhony®を用いた音素レベルの発音フィードバック
<img width="386" height="314" alt="image" src="https://github.com/user-attachments/assets/d48ceba7-1bc3-4705-9e92-cf7752baeeda" />

### 継続的な発音練習を促す「ゲーミフィケーション要素」
- レッスンの完了などでアプリ内でバッジを獲得
- ポイントやバッジの保有数を他ユーザと比べられるランキング機能
- アプリ内の行動に応じてポイントを獲得
- 知見や感想を他ユーザと共有できるコメント機能

<img width="768" height="391" alt="image" src="https://github.com/user-attachments/assets/ceddbe76-e6ad-44a6-970a-27f64ce06074" />

## システム構成
いつでも手軽にはじめられるように、Webアプリとして実装してPC・スマホどちらからでも利用できるようにしました。データベースにはサーバーレスDBであるSupabaseを採用し、利用者の情報管理をおこないました。
フロントエンドUIの実装にはNext.js/TypeScriptを利用しました。
